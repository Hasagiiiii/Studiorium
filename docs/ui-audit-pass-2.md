# UI Audit — Pass 2

Refs #87

Este incremento concentra a reconstrução social-first no mobile sem misturar áreas ainda não revisadas.

## Entregue nesta passagem
- composer da Home transformado em superfície social expansível com quatro caminhos claros: Pesquisa, Discussão, Projeto e Criação;
- redução de elementos editoriais redundantes no mobile para priorizar feed;
- comunidade compactada para leitura e ação mais rápidas;
- títulos, estatísticas, membership, tabs e listas ajustados para telas pequenas;
- safe-area preservada;
- reduced motion respeitado;
- teste de regressão para a estrutura do composer e proteções mobile.

## Próximas passagens
- corrigir perfis inconsistentes/indisponíveis;
- tornar a comunidade um feed contextual, com membros e atividades recentes;
- adicionar ações sociais uniformes aos tipos de post;
- revisar Explorar e busca global;
- revisar notícias e leitura longa;
- revisar ADM, Escrivaninha, autenticação e estados assíncronos.
